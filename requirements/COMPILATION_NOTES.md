# Requirements Compilation Notes

## ⚠️ IMPORTANT: Python Version for Compilation

**ALL requirements files MUST be compiled using Python 3.10** (the minimum supported version).

### Why This Matters

When you run `pip-compile`, it uses the **currently active Python interpreter** to determine:
1. Which package versions are compatible
2. Which backport packages are needed (e.g., `importlib-metadata`, `backports-tarfile`)
3. Platform-specific dependencies

**Compiling with Python 3.12 when you support Python 3.10** will result in:
- ❌ Missing backport packages that Python 3.10 users need
- ❌ Potentially incompatible package versions
- ❌ Installation failures on Python 3.10 systems
- ❌ Violation of compatibility guarantees

### How to Fix

1. **Set up Python 3.10 environment**:
   ```bash
   # Using pyenv (recommended)
   pyenv install 3.10.15
   pyenv local 3.10.15
   
   # Or using system Python 3.10
   python3.10 --version  # Verify it's 3.10.x
   ```

2. **Verify you're using Python 3.10**:
   ```bash
   python --version
   # Must show: Python 3.10.x
   ```

3. **Clean and recompile**:
   ```bash
   cd requirements/
   make clean
   make compile
   ```

4. **Verify the output**:
   ```bash
   head -n 5 requirements/*.txt
   # All should now show: "Python 3.10"
   ```

### Verification Checklist

After recompiling with Python 3.10:

- [ ] Header comments in all .txt files show "Python 3.10"
- [ ] Test installation on Python 3.10: `python3.10 -m pip install -r requirements/all.txt`
- [ ] Test installation on Python 3.11: `python3.11 -m pip install -r requirements/all.txt`
- [ ] Test installation on Python 3.12: `python3.12 -m pip install -r requirements/all.txt`
- [ ] Verify imports work: `python3.10 -c "import jaraco.context; import keyring"`
- [ ] Check for backport packages (should be present if needed):
  ```bash
  grep -E "backports-|importlib-metadata" requirements/all.txt
  ```

### Expected Differences When Compiled with Python 3.10

When properly compiled with Python 3.10, you may see:

1. **Additional backport packages**:
   - `backports-tarfile` (if needed by jaraco-context on Python 3.10/3.11)
   - `importlib-metadata` (backport for Python <3.12)

2. **Different dependency comments**:
   - Packages may show different "via" relationships
   - Transitive dependencies may change based on Python version requirements

### Common Mistakes

❌ **Don't do this**:
```bash
# Using whatever Python is active
make compile  # Could be Python 3.11, 3.12, etc.
```

✅ **Do this instead**:
```bash
# Explicitly using Python 3.10
pyenv local 3.10.15  # or equivalent
python --version     # Verify!
make compile
```

### CI/CD Integration

The CI system should verify requirements are compiled with Python 3.10:

```yaml
# .github/workflows/check-requirements.yml (example)
- name: Verify requirements compiled with Python 3.10
  run: |
    if grep -q "Python 3.12" requirements/*.txt; then
      echo "ERROR: Requirements compiled with wrong Python version"
      echo "Requirements must be compiled with Python 3.10"
      exit 1
    fi
```
