Protocol-Based Design:
  SegmentationBackend (Protocol)
  ├── info: SegmentationBackendInfo
  ├── load(device, weights_path)
  └── segment(image) -> Dict[str, Tuple[np.ndarray, float]]

Backend Implementations:
  1. StubBackend
     - Returns empty dict (production-safe default)
     - Zero dependencies
     - Always available

  2. EfficientSAMBackend
     - V1: Heuristic color segmentation (fallback)
     - V2: Real EfficientSAM + CLIP (conditional)
     - Confidence scoring (0.0-1.0)
     - Materials: glass, water, foliage, stone, metal, etc.

Key Features:
  • Lazy loading (models on first inference)
  • LRU caching (maxsize=2)
  • Device auto-detection (MPS > CUDA > CPU)
  • Fail-safe fallback (stub on missing deps)
  • Strict mode (optional error propagation)
  • Confidence scoring with CLIP
