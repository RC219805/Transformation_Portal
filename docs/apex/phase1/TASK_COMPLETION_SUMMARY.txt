KEY ARCHITECTURAL DECISIONS
================================================================================

1. Verdict Semantics
   - pass_fail: strictly pass|warn|fail
   - Insufficient data: metadata flag (not a verdict)

2. Dry-Run Enforcement
   - Real pipeline requires explicit bypass
   - Prevents synthetic-data gating accidents

3. Ledger Scoping
   - Aggregation requires run_id + commit_sha
   - Prevents mixed-commit contamination

4. Minimum Sample Size
   - n >= 20 required for statistical validity
   - Below threshold: insufficient_data flag
