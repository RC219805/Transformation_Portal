**Why**: Prevent polluted dependency PRs from ever being created, even if indexes drift.

**Implementation**: Add to `.github/workflows/dependency-update.yml` after the "Update dependencies" step:

```yaml
- name: Guardrail - fail if CUDA/NVIDIA deps appear
  run: |
    if rg -n '^(nvidia-|triton\b)' requirements/ml.txt; then
      echo "ERROR: CUDA/NVIDIA packages detected in requirements/ml.txt"
      echo "The workflow is configured for CPU-only PyTorch."
      echo "If GPU support is needed, update the governance policy first."
      exit 1
    fi
```

**Benefits**:
- Workflow fails before PR creation if CUDA packages appear
- Self-healing even if PIP_INDEX_URL configuration drifts
- Clear error message for developers
