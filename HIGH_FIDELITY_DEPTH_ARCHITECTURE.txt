KEY IMPROVEMENTS vs CURRENT PIPELINE
=====================================

ISSUE 1: Low-Resolution Inference → FIXED
  Before: Depth predicted at ~few hundred pixels, bicubic to 4K
  After:  Tiled inference at native model resolution (1024×1024 tiles)
  Impact: 5-10x edge fidelity, eliminates smooth ramps

ISSUE 2: Wrong Normal Maps → FIXED
  Before: Excessive Z scale → uniform purple/blue
  After:  Correct Z scale (1.0) with normalized depth
  Impact: Normals become usable for Material Response and relighting

ISSUE 3: Misleading Metrics → FIXED
  Before: "Edge gradient ≥180" (wrong scaling, wrong proxy)
  After:  Edge alignment score (RGB-depth correlation)
  Impact: Optimize for actual DOF/masking quality

ISSUE 4: Edge-Blurring Ensemble → TO FIX
  Before: Weighted average (50/35/15) smears boundaries
  After:  Median fusion (preserves discontinuities)
  Impact: 2-3x edge quality improvement

ISSUE 5: Edge-Smoothing Filter → TO FIX
  Before: Guided filter (r=10, eps=0.02) washes out edges
  After:  Joint bilateral upsampling / edge snapping
  Impact: Tighter boundaries, less washout

USAGE EXAMPLE
=============

from lux_depth_v2.depth_inference import create_tiled_estimator
from lux_depth_v2.normal_map import generate_normal_map
from lux_depth_v2.quality_metrics import quick_quality_check

# Step 1: High-fidelity depth
estimator = create_tiled_estimator(tile_size=1024, overlap=128)
depth = estimator.estimate_depth(rgb_image)

# Step 2: Correct normals
depth_uint16 = (depth * 65535).astype(np.uint16)
normals = generate_normal_map(depth_uint16, preset="architectural")

# Step 3: Quality validation
metrics = quick_quality_check(rgb_image, depth, depth_uint16)
print(f"Edge alignment: {metrics.edge_alignment_score:.3f}")
print(f"Overall quality: {metrics.overall_quality_score:.1f}/100")
