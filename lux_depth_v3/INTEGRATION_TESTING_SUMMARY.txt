TROUBLESHOOTING
================================================================

If installation fails:
  - Try CPU-only PyTorch:
    pip install torch --index-url https://download.pytorch.org/whl/cpu
  - Check PyTorch installed before DA3:
    python3 -c "import torch; print(torch.__version__)"
  - See TESTING_STATUS_REPORT.md Troubleshooting section

If tests fail:
  - Verify all imports work:
    python3 -c "import torch, depth_anything_3, numpy, PIL, pytest"
  - Run tests with verbose output:
    pytest tests/ -v --tb=short
  - See TESTING_STATUS_REPORT.md for detailed guidance

If E2E test fails:
  - Check test images exist: ls -la test_images/
  - Try smaller model: lux-depth-v3 enhance --model small ...
  - Check verbose output for specific errors
