# Projects Directory

Client/property-specific processing workflows and documentation.

## Purpose
This directory contains real-world examples of Transformation Portal pipelines
applied to specific properties. Each project demonstrates:
- Parameter tuning strategies
- Multi-stage processing workflows
- Material Response and depth-aware techniques
- Production-quality output configuration

## Structure
Each project should include:
- Processing scripts (Python)
- Configuration files (YAML)
- Documentation (Markdown)
- Example presets

## Active Projects
- **750_picacho_lane/**: Pool depth processing with atmospheric enhancement
- **montecito_shores/**: Luxury interior Material Response workflow

## Guidelines
1. Sanitize client-sensitive information before committing
2. Document parameter decisions and trade-offs
3. Include before/after comparisons where possible
4. Use meaningful script names (e.g., `process_pool_depth.py`)
