### 2. Materials V2/V3 Not Enabled ⚠️
**Issue**: Segmentation ran, but advanced Materials V2/V3 engines were OFF

**Evidence**:
```
materials_v2_enabled: false
materials_v3_enabled: false
material_mods: "material_segmentation" (basic only)
segmentation.backend: "auto" → selected "HeuristicMaterialSegmenter"
segmentation.allow_downloads: false (blocks SegFormer)
```

**Root Cause**: Preset difference
- **Used**: `interior_luxury` (lines 642-660 in config.py)
  - Basic material strength: 0.90
  - Segmentation: HeuristicMaterialSegmenter (fast, no downloads)
  - Materials V2: NOT enabled
  - Materials V3: NOT enabled

- **Available**: `interior_luxury_max_quality` (lines 662-700)
  - Materials V2: ENABLED
  - Segmentation: SegFormer-B5 @ 1280px
  - Requires downloads: True

**Why HeuristicMaterialSegmenter was selected**:
1. Preset uses backend="auto"
2. allow_downloads=false blocks SegFormer weights
3. Fallback: HeuristicMaterialSegmenter (0.823s runtime)
4. This is FAST but BASIC (color/texture heuristics, not deep learning)

**Segmentation Runtime Analysis**:
- 0.823s for 3600×6000 image is consistent with heuristic segmentation
- SegFormer-B5 would take 5-15s for same image
- Trade-off: Speed vs. accuracy
