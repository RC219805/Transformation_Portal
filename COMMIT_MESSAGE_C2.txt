feat(spatial_ai): Implement Phase C.2 Confidence Semantics for SAM2

Replace hardcoded placeholder scores (1.0) with real SAM2 IoU and stability
predictions. This enhancement improves segmentation quality assessment and
enables intelligent mask filtering based on confidence.

## Changes

### Core Implementation
- Add `_extract_sam2_predictions()` helper method to defensively extract
  masks, IoU scores, and stability scores from SAM2 model output
- Implement fallback to 1.0 when attributes missing (stub backend support)
- Update segment method patterns to use real scores instead of placeholders

### Features
- ✅ Real SAM2 IoU predictions used for SegmentationResult.scores
- ✅ Real SAM2 stability scores populate MaskMetadata.stability_score
- ✅ Defensive attribute checking (hasattr + None checks)
- ✅ Automatic type conversion to float32 for consistency
- ✅ Zero exceptions on missing attributes
- ✅ 100% backward compatible with stub backends

### Testing

  - Fallback behavior (missing attributes, None values)

## Integration Guide

When implementing SAM2 segmentation modes, use the new pattern:

```python
# Extract real SAM2 predictions (Phase C.2)
masks, iou_scores, stability_scores = self._extract_sam2_predictions(model_output)

# Use real scores in metadata
metadata = MaskMetadata(
    area=area,
    bbox=bbox,
    stability_score=stability_scores[i],  # Real SAM2 confidence
)

# Use real IoU for result scores
return SegmentationResult(
    masks=masks,
    scores=iou_scores,  # Real SAM2 IoU predictions
    metadata=metadata_list,
)
```
