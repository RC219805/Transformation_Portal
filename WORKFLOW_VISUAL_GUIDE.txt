2. PROCESSING PIPELINE (10 STEPS)
================================================================================

Step 1: LOAD & ANALYZE
    ┌──────────────────────────────────────────────────────┐
    │  Load with tifffile (HDR-aware)                      │
    │  Measure: brightness, saturation, sky B/R            │
    │  Establish baseline metrics                          │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 2: EXPOSURE LIFT
    ┌──────────────────────────────────────────────────────┐
    │  Global Lift        → +15-30% (content-dependent)    │
    │  Shadow Recovery    → +20-30 levels (<70/255)        │
    │  Midtone Boost      → +5-8% (Gaussian weighted)      │
    │  Highlight Protect  → Preserve >230/255              │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 3: COLOR GRADING
    ┌──────────────────────────────────────────────────────┐
    │  Saturation Boost   → +8-12% (HSV-based)             │
    │  Warmth Adjust      → R±1-2%, B∓1-2%                 │
    │  Hue Preservation   → HSV transform maintains hue    │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 4: ⭐ SKY NEUTRALITY PROTECTION ⭐
    ┌──────────────────────────────────────────────────────┐
    │  Detect Sky         → Brightness >200/255            │
    │  Measure B/R        → Current ratio                  │
    │  Neutralize         → If not 0.98-1.02               │
    │  Smooth Mask        → Gaussian σ=5                   │
    │  Target: B/R = 0.98-1.02 (neutral)                   │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 5: ZONE-BASED CLARITY
    ┌──────────────────────────────────────────────────────┐
    │  Shadow Zone    (<0.3)  → 6% strength (gentle)       │
    │  Midtone Zone   (0.3-0.7) → 12% strength (primary)   │
    │  Highlight Zone (>0.7)  → 8% strength (moderate)     │
    │  Method: Unsharp mask with zone weighting            │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 6: EDGE SHARPENING
    ┌──────────────────────────────────────────────────────┐
    │  Edge Detection     → Find Edges filter              │
    │  Unsharp Mask       → radius=1.3, 150%               │
    │  Selective Blend    → 14% strength                   │
    │  Smooth Transitions → Gaussian edge mask             │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 7: MICRO-CONTRAST
    ┌──────────────────────────────────────────────────────┐
    │  Boost              → +4% contrast                   │
    │  Target             → Midtones only (±0.2σ)          │
    │  Purpose            → Depth perception               │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 8: QUALITY VALIDATION
    ┌──────────────────────────────────────────────────────┐
    │  ✓ Brightness       → Appropriate for scene          │
    │  ✓ Sky B/R          → 0.98-1.02 (if present)         │
    │  ✓ Clipping         → <0.5%                          │
    │  ✓ Saturation       → Natural, not oversaturated     │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 9: 16-BIT CONVERSION
    ┌──────────────────────────────────────────────────────┐
    │  float32 → uint16 (0-65535 range)                    │
    │  Preserve full tonal range                           │
    │  Professional output standard                        │
    └──────────────────────────────────────────────────────┘
                            ↓

Step 10: EXPORT
    ┌──────────────────────────────────────────────────────┐
    │  Master:  16-bit TIFF + LZW compression              │
    │  Preview: High-quality JPG (95%)                     │
    │  Compare: Side-by-side validation                    │
    └──────────────────────────────────────────────────────┘
                            ↓
    ┌──────────────────────────────────────────────────────┐
    │              OUTPUT FILES READY                      │
    │         ✅ Production Quality Achieved               │
    └──────────────────────────────────────────────────────┘

6. COMMON ISSUES & SOLUTIONS MAP
================================================================================

CYAN SKY ARTIFACTS
    Problem:  Sky develops artificial cyan/turquoise tint
    Cause:    RGB channel manipulation without sky masking
    Solution: Enable SKY_PROTECTION = True (Step 4)
    Document: GREATROOM_MASTER_SUMMARY.md

IMAGE TOO DARK
    Problem:  Result darker than original
    Cause:    Overly conservative EXPOSURE_LIFT
    Solution: Increase to 0.20-0.30 for dark images
    Document: GREATROOM_FINAL_SUMMARY.md

NOISY SHADOWS
    Problem:  Shadow regions look grainy
    Cause:    Excessive CLARITY in shadow zones
    Solution: Reduce to 0.06 or less
    Document: PROCESSING_QUICK_REFERENCE.md

LOST MATERIAL DETAIL
    Problem:  Wood grain, textures unclear
    Cause:    Uniform enhancement without zones
    Solution: Enable zone-based clarity (Step 5)
    Document: GREATROOM_FINAL_APPROACH.md

HUE SHIFT
    Problem:  Colors look wrong, shifted hue
    Cause:    RGB multiplication for saturation
    Solution: Use HSV transformation (Step 3)
    Document: PROCESSING_QUICK_REFERENCE.md

OVEREXPOSED HIGHLIGHTS
    Problem:  Bright areas blown out
    Cause:    Insufficient highlight protection
    Solution: Lower HIGHLIGHT_PROTECT threshold (235→225)
    Document: GREATROOM_FINAL_APPROACH.md
