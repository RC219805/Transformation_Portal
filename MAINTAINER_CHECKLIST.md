# PR #579 - Maintainer Action Checklist

## Overview
This checklist provides step-by-step instructions for resolving the PR #579 review comments. The core issue is that requirements were compiled with Python 3.12 instead of Python 3.10 (minimum supported version).

## Prerequisites
- [ ] Access to Python 3.10 environment (pyenv recommended)
- [ ] pip-tools installed: `pip install pip-tools`
- [ ] Clean working directory: `git status` shows no uncommitted changes

## Step 1: Set Up Python 3.10 Environment

### Option A: Using pyenv (Recommended)
```bash
# Install Python 3.10 if not already installed
pyenv install 3.10.15

# Navigate to requirements directory
cd requirements/

# Set Python 3.10 for this directory
pyenv local 3.10.15

# Verify Python version
python --version
# Should output: Python 3.10.15 (or similar 3.10.x)
```

### Option B: Using system Python 3.10
```bash
# Verify Python 3.10 is available
python3.10 --version

# Create alias (for this session)
alias python=python3.10

# Verify
python --version
# Should output: Python 3.10.x
```

**Checkpoint**: 
- [ ] Python version is 3.10.x (verify with `python --version`)

## Step 2: Verify Makefile Check Works

```bash
cd requirements/

# Test the Python version check
make check-python
# Should output: ✓ Python version is correct
```

**If error occurs**: Your Python is not 3.10. Return to Step 1.

**Checkpoint**:
- [ ] `make check-python` passes without error

## Step 3: Clean and Recompile Requirements

```bash
cd requirements/

# Clean old compiled files
make clean

# Recompile with Python 3.10
make compile
```

**Expected output**:
```
Current Python version: 3.10
Required Python version: 3.10
✓ Python version is correct
Compiling all.txt (global resolution)...
Compiling base.txt...
Compiling ml.txt...
Compiling dev.txt...
Compiling ci.txt...
✓ All requirements compiled successfully with Python 3.10
```

**If compilation fails**:
- Check constraints.txt is present
- Verify pip-tools is installed: `pip list | grep pip-tools`
- Check error messages for missing dependencies

**Checkpoint**:
- [ ] Compilation completed without errors
- [ ] All .txt files regenerated (check timestamps: `ls -l *.txt`)

**Checkpoint**:
- [ ] All .txt files show "Python 3.10" in header (not 3.11 or 3.12)
